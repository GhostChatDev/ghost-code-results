# Quillstack design

A calm, editorial workspace for writing and finding notes. Data is stored in PostgreSQL; no sample notes are presented as real data.

- Palette: background #f6f5f1, surface #ffffff, border #e5e3db, text #252823, muted #686d63, accent #4e6548, success #315e43, danger #a13333.
- Typography: system sans-serif; 14px supporting text, 16px body, 22px section headings, 32px page heading. Figures use tabular numerals.
- Spacing: 4, 8, 12, 16, 24, 32px. Radii: 8px and 12px.
- Components: app shell, sidebar, search, note list, editor, Markdown preview, tags, badges, history panel, conflict dialog, feedback messages and export actions.
- Responsive: desktop three-column workspace, stacked note list and editor on small screens. Controls have visible focus and generous touch targets.
